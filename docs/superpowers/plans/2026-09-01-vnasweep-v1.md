# vnasweep v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Tauri desktop app that does in-app OSL calibration of a NanoVNA-H, sweeps an antenna's SWR once, and saves/labels/overlays the results as flat files.

**Architecture:** Rust backend in `src-tauri/` owns all serial I/O, the OSL calibration math, the SWR math, and flat-file storage under `~/vnasweep/`. Pure modules (`complex`, `cal`, `sweep`, `store` logic) are unit-tested with synthetic data; `nanovna` device I/O is verified against the real device. The Svelte 5 frontend is a two-tab render layer (Measure, Library) that calls `#[tauri::command]`s and draws with uPlot.

**Tech Stack:** Rust, Tauri 2, `serialport`, `serde`/`serde_json`, `chrono`, `tauri-plugin-dialog`; Svelte 5, Vite, uPlot, `@tauri-apps/plugin-dialog`.

**Spec:** `docs/superpowers/specs/2026-09-01-vnasweep-v1-design.md` — read it alongside this plan.

## Global Constraints

- `src-tauri` crate is `edition = "2024"`. Workspace root has no crate of its own.
- `#![forbid(unsafe_code)]` at the `src-tauri` crate root (already present).
- Every `#[tauri::command]` returns `Result<T, String>`; the `Err` string is user-facing. No `unwrap`/`expect`/`panic!` on any command path or in `store.rs`.
- Version control is **`jj`**, not `git`. Commit with: `jj describe -m "<msg>"` then `jj bookmark set main -r @` then `jj new`. Never `git commit`.
- Personal project: work directly on `main`, commit per task, never open a PR. No remote is configured (needs the home network); do not attempt `jj git push`.
- All NanoVNA shell wire quirks live only in `src-tauri/src/nanovna.rs`. The shell echoes each command and ends every reply with `ch> `.
- Reflection reference impedance `Z0 = 50.0` ohms.
- SWR is reported as `999.0` when `|Γ| >= 1.0`.
- Storage root: `$VNASWEEP_HOME` if set, else `$HOME/vnasweep`. Subdirs `cals/` and `readings/`. Created on first write.
- Touchstone output: `# MHz S RI R 50`, frequency in MHz, one `freq re im` triple per line.
- Rust struct names and their TS mirrors in `src/lib/types.ts` are kept in sync by hand.
- Test runner for Rust: `cargo test --manifest-path src-tauri/Cargo.toml`. Full gate: `just check` (via `direnv exec . just check` if `just` is not on PATH).
- macOS serial node: `/dev/cu.*`, not `/dev/tty.*` (`autodetect` already normalizes this).

```rust
//! Minimal complex arithmetic for the OSL calibration math. No dependency on
//! `num-complex` — only the handful of ops `cal.rs` and `sweep.rs` need.

use core::ops::{Add, Div, Mul, Sub};

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Complex {
    pub re: f64,
    pub im: f64,
}

impl Complex {
    pub const fn new(re: f64, im: f64) -> Self {
        Self { re, im }
    }

    pub fn abs(self) -> f64 {
        self.re.hypot(self.im)
    }

    pub fn is_finite(self) -> bool {
        self.re.is_finite() && self.im.is_finite()
    }
}

impl Add for Complex {
    type Output = Complex;
    fn add(self, o: Complex) -> Complex {
        Complex::new(self.re + o.re, self.im + o.im)
    }
}

impl Sub for Complex {
    type Output = Complex;
    fn sub(self, o: Complex) -> Complex {
        Complex::new(self.re - o.re, self.im - o.im)
    }
}

impl Mul for Complex {
    type Output = Complex;
    fn mul(self, o: Complex) -> Complex {
        Complex::new(
            self.re * o.re - self.im * o.im,
            self.re * o.im + self.im * o.re,
        )
    }
}

impl Mul<f64> for Complex {
    type Output = Complex;
    fn mul(self, k: f64) -> Complex {
        Complex::new(self.re * k, self.im * k)
    }
}

impl Div for Complex {
    type Output = Complex;
    fn div(self, o: Complex) -> Complex {
        let d = o.re * o.re + o.im * o.im;
        Complex::new(
            (self.re * o.re + self.im * o.im) / d,
            (self.im * o.re - self.re * o.im) / d,
        )
    }
}
```

```rust
//! One-port 3-term OSL error model. See
//! `docs/superpowers/specs/2026-09-01-vnasweep-v1-design.md` §5.
//!
//! Model:  Γm = e00 + (e10·e01 · Γa) / (1 - e11·Γa)
//!   e00     = directivity          (equals the Load measurement, since Γ_load = 0)
//!   e11     = source match
//!   e10·e01 = reflection tracking  (stored as one product)
//! Standards are ideal for v1: Γ_open = +1, Γ_short = -1, Γ_load = 0.

use crate::complex::Complex;
use crate::model::{ErrorTerms, RawTrace, Standards};

fn cx(p: &crate::model::RawPoint) -> Complex {
    Complex::new(p.re, p.im)
}

pub fn solve_osl(std: &Standards) -> Result<ErrorTerms, String> {
    let n = std.open.points.len();
    if n == 0 {
        return Err("calibration sweeps are empty".into());
    }
    if std.short.points.len() != n || std.load.points.len() != n {
        return Err(format!(
            "standard sweeps have different point counts: open {}, short {}, load {}",
            n,
            std.short.points.len(),
            std.load.points.len()
        ));
    }

    let one = Complex::new(1.0, 0.0);
    let mut e00 = Vec::with_capacity(n);
    let mut e11 = Vec::with_capacity(n);
    let mut e10e01 = Vec::with_capacity(n);

    for i in 0..n {
        let g_open = cx(&std.open.points[i]);
        let g_short = cx(&std.short.points[i]);
        let g_load = cx(&std.load.points[i]);

        let d = g_load; // e00
        let mo = g_open - d;
        let ms = g_short - d;

        let denom = mo - ms;
        if denom.abs() < 1e-12 {
            return Err(format!(
                "point {i}: open and short measurements are indistinguishable — bad standards or a loose connection?"
            ));
        }

        let b = (mo + ms) / denom; // e11
        let a = mo * (one - b); // e10·e01

        if !d.is_finite() || !b.is_finite() || !a.is_finite() {
            return Err(format!("point {i}: solved a non-finite error term"));
        }

        e00.push([d.re, d.im]);
        e11.push([b.re, b.im]);
        e10e01.push([a.re, a.im]);
    }

    Ok(ErrorTerms { e00, e11, e10e01 })
}

pub fn apply(raw: &RawTrace, terms: &ErrorTerms) -> Result<Vec<Complex>, String> {
    let n = raw.points.len();
    if terms.e00.len() != n {
        return Err(format!(
            "sweep has {n} points but the calibration has {}; sweep at the calibration's span",
            terms.e00.len()
        ));
    }

    let mut out = Vec::with_capacity(n);
    for i in 0..n {
        let gm = cx(&raw.points[i]);
        let e00 = Complex::new(terms.e00[i][0], terms.e00[i][1]);
        let e11 = Complex::new(terms.e11[i][0], terms.e11[i][1]);
        let a = Complex::new(terms.e10e01[i][0], terms.e10e01[i][1]);

        // Γa = (Γm - e00) / (e10·e01 + e11·(Γm - e00))
        let d = gm - e00;
        out.push(d / (a + e11 * d));
    }
    Ok(out)
}

//! SWR, impedance, and trace-level statistics. Pure. See spec §5.3, §5.5.

use crate::complex::Complex;
use crate::model::{Band, RawTrace, SwrPoint, TracePoint};

const Z0: f64 = 50.0;

pub fn swr(gamma: Complex) -> f64 {
    let g = gamma.abs();
    if g >= 1.0 {
        return 999.0;
    }
    (1.0 + g) / (1.0 - g)
}

pub fn impedance(gamma: Complex) -> (f64, f64) {
    // Z = Z0 · (1 + Γ) / (1 - Γ)
    let one = Complex::new(1.0, 0.0);
    let z = Complex::new(Z0, 0.0) * ((one + gamma) / (one - gamma));
    (z.re, z.im)
}

pub fn return_loss_db(gamma: Complex) -> f64 {
    let g = gamma.abs();
    if g <= 0.0 {
        return f64::INFINITY;
    }
    -20.0 * g.log10()
}

pub fn build_trace(raw: &RawTrace, corrected: &[Complex]) -> Vec<TracePoint> {
    debug_assert_eq!(raw.points.len(), corrected.len());
    raw.points
        .iter()
        .zip(corrected)
        .map(|(p, &g)| {
            let (r, x) = impedance(g);
            TracePoint {
                freq_hz: p.freq_hz,
                gamma_re: g.re,
                gamma_im: g.im,
                swr: swr(g),
                r,
                x,
                return_loss_db: return_loss_db(g),
            }
        })
        .collect()
}

pub fn min_swr(trace: &[TracePoint]) -> SwrPoint {
    trace
        .iter()
        .min_by(|a, b| a.swr.partial_cmp(&b.swr).unwrap_or(std::cmp::Ordering::Equal))
        .map(|p| SwrPoint { freq_hz: p.freq_hz, swr: p.swr })
        .unwrap_or(SwrPoint { freq_hz: 0, swr: 999.0 })
}

pub fn swr_bandwidth(trace: &[TracePoint], threshold: f64) -> Option<Band> {
    if trace.is_empty() {
        return None;
    }
    let mi = trace
        .iter()
        .enumerate()
        .min_by(|(_, a), (_, b)| a.swr.partial_cmp(&b.swr).unwrap_or(std::cmp::Ordering::Equal))
        .map(|(i, _)| i)?;
    if trace[mi].swr > threshold {
        return None;
    }

    // Linear interpolation of the frequency where swr crosses `threshold`
    // between samples `lo` (below threshold) and `hi` (above threshold).
    let cross = |lo: &TracePoint, hi: &TracePoint| -> u64 {
        let span_swr = hi.swr - lo.swr;
        if span_swr.abs() < f64::EPSILON {
            return lo.freq_hz;
        }
        let frac = (threshold - lo.swr) / span_swr;
        let f = lo.freq_hz as f64 + frac * (hi.freq_hz as f64 - lo.freq_hz as f64);
        f.round() as u64
    };

    // Walk left from the minimum.
    let mut lo_hz = trace[0].freq_hz;
    for j in (0..mi).rev() {
        if trace[j].swr > threshold {
            lo_hz = cross(&trace[j + 1], &trace[j]);
            break;
        }
    }

    // Walk right from the minimum.
    let mut hi_hz = trace[trace.len() - 1].freq_hz;
    for j in (mi + 1)..trace.len() {
        if trace[j].swr > threshold {
            hi_hz = cross(&trace[j - 1], &trace[j]);
            break;
        }
    }

    Some(Band { lo_hz, hi_hz, threshold })
}

//! `cals/<slug>.json` — full `Calibration`.
//! `readings/<slug>.s1p` — Touchstone; `readings/<slug>.json` — metadata sidecar.
//! Reading stats (`min_swr`, `bandwidth`) are derived on load, never stored.

use std::fs;
use std::io::Write;
use std::path::{Path, PathBuf};

use crate::model::{
    Band, CalMeta, Calibration, Reading, ReadingMeta, SwrPoint, TracePoint,
};
use crate::sweep::{min_swr, swr_bandwidth};

const SWR_BANDWIDTH_THRESHOLD: f64 = 2.0;

pub fn home() -> PathBuf {
    if let Ok(p) = std::env::var("VNASWEEP_HOME") {
        return PathBuf::from(p);
    }
    let home = std::env::var("HOME").unwrap_or_else(|_| ".".into());
    PathBuf::from(home).join("vnasweep")
}

fn cals_dir() -> PathBuf {
    home().join("cals")
}
fn readings_dir() -> PathBuf {
    home().join("readings")
}

fn ensure_dir(p: &Path) -> Result<(), String> {
    fs::create_dir_all(p).map_err(|e| format!("creating {}: {e}", p.display()))
}

fn write_atomic(path: &Path, contents: &str) -> Result<(), String> {
    if let Some(parent) = path.parent() {
        ensure_dir(parent)?;
    }
    let tmp = path.with_extension("tmp");
    {
        let mut f = fs::File::create(&tmp).map_err(|e| format!("writing {}: {e}", tmp.display()))?;
        f.write_all(contents.as_bytes())
            .map_err(|e| format!("writing {}: {e}", tmp.display()))?;
    }
    fs::rename(&tmp, path).map_err(|e| format!("finalizing {}: {e}", path.display()))
}

pub fn slugify(name: &str, taken: impl Fn(&str) -> bool) -> String {
    let mut s: String = name
        .trim()
        .to_lowercase()
        .chars()
        .map(|c| if c.is_ascii_alphanumeric() { c } else { '-' })
        .collect();
    s = s.split('-').filter(|p| !p.is_empty()).collect::<Vec<_>>().join("-");
    if s.is_empty() {
        s = "untitled".to_string();
    }
    if !taken(&s) {
        return s;
    }
    let mut n = 2u32;
    loop {
        let candidate = format!("{s}-{n}");
        if !taken(&candidate) {
            return candidate;
        }
        n += 1;
    }
}

fn json_files(dir: &Path) -> Vec<PathBuf> {
    let mut out = Vec::new();
    if let Ok(rd) = fs::read_dir(dir) {
        for e in rd.flatten() {
            let p = e.path();
            if p.extension().and_then(|s| s.to_str()) == Some("json") {
                out.push(p);
            }
        }
    }
    out.sort();
    out
}

    let side_path = readings_dir().join(format!("{id}.json"));
    let side = fs::read_to_string(&side_path).map_err(|e| format!("reading {}: {e}", side_path.display()))?;
    let meta: ReadingMeta = serde_json::from_str(&side).map_err(|e| format!("parsing {}: {e}", side_path.display()))?;

    let s1p_path = readings_dir().join(format!("{id}.s1p"));
    let s1p = fs::read_to_string(&s1p_path).map_err(|e| format!("reading {}: {e}", s1p_path.display()))?;
    let trace = parse_touchstone(&s1p)?;

    let min = min_swr(&trace);
    let band = swr_bandwidth(&trace, SWR_BANDWIDTH_THRESHOLD);

pub fn write_reading(reading: &Reading) -> Result<ReadingMeta, String> {

    write_atomic(&readings_dir().join(format!("{}.s1p", reading.meta.id)), &s1p)?;
    let side = serde_json::to_string_pretty(&reading.meta).map_err(|e| format!("serializing sidecar: {e}"))?;
    write_atomic(&readings_dir().join(format!("{}.json", reading.meta.id)), &side)?;

}

// ---- Touchstone -------------------------------------------------------

fn render_touchstone(r: &Reading) -> String {
    let mut out = String::new();
    out.push_str(&format!(
        "! vnasweep  {}  {}  cal: {}\n",
        r.meta.name, r.meta.created, r.meta.cal_name
    ));
    out.push_str("# MHz S RI R 50\n");
    for p in &r.trace {
        out.push_str(&format!(
            "{:.6}  {:.9}  {:.9}\n",
            p.freq_hz as f64 / 1e6,
            p.gamma_re,
            p.gamma_im
        ));
    }
    out
}

/// Parse a 1-port RI Touchstone into `TracePoint`s. `swr`/`r`/`x`/`return_loss_db`
/// are recomputed from Γ so a hand-edited file stays self-consistent.
fn parse_touchstone(text: &str) -> Result<Vec<TracePoint>, String> {
    use crate::complex::Complex;
    use crate::sweep::{impedance, return_loss_db, swr};

    let mut freq_scale = 1e6_f64; // default MHz
    let mut pts = Vec::new();
    for line in text.lines() {
        let line = line.trim();
        if line.is_empty() || line.starts_with('!') {
            continue;
        }
        if let Some(rest) = line.strip_prefix('#') {
            let up = rest.to_uppercase();
            freq_scale = if up.contains("GHZ") {
                1e9
            } else if up.contains("KHZ") {
                1e3
            } else if up.contains(" HZ") || up.starts_with("HZ") {
                1.0
            } else {
                1e6
            };
            continue;
        }
        let mut it = line.split_whitespace();
        let f: f64 = it.next().ok_or("touchstone: missing frequency")?.parse().map_err(|_| "touchstone: bad frequency")?;
        let re: f64 = it.next().ok_or("touchstone: missing real part")?.parse().map_err(|_| "touchstone: bad real part")?;
        let im: f64 = it.next().ok_or("touchstone: missing imag part")?.parse().map_err(|_| "touchstone: bad imag part")?;
        let g = Complex::new(re, im);
        let (r, x) = impedance(g);
        pts.push(TracePoint {
            freq_hz: (f * freq_scale).round() as u64,
            gamma_re: re,
            gamma_im: im,
            swr: swr(g),
            r,
            x,
            return_loss_db: return_loss_db(g),
        });
    }
    if pts.is_empty() {
        return Err("touchstone: no data rows".into());
    }
    Ok(pts)
}

use crate::model::{RawPoint, RawTrace};

/// Pair the `frequencies` output (one integer Hz per line) with the `data 0`
/// output (one `re im` pair per line). Blank lines are ignored.
fn parse_sweep(frequencies: &str, data: &str) -> Result<RawTrace, String> {
    let freqs: Vec<u64> = frequencies
        .lines()
        .filter_map(|l| {
            let t = l.trim();
            if t.is_empty() { None } else { t.parse::<u64>().ok() }
        })
        .collect();

    let samples: Vec<(f64, f64)> = data
        .lines()
        .filter_map(|l| {
            let mut it = l.split_whitespace();
            let re = it.next()?.parse::<f64>().ok()?;
            let im = it.next()?.parse::<f64>().ok()?;
            Some((re, im))
        })
        .collect();

    if freqs.is_empty() {
        return Err("sweep returned no frequency points".into());
    }
    if freqs.len() != samples.len() {
        return Err(format!(
            "sweep frequency count ({}) and data count ({}) disagree",
            freqs.len(),
            samples.len()
        ));
    }

    Ok(RawTrace {
        points: freqs
            .into_iter()
            .zip(samples)
            .map(|(freq_hz, (re, im))| RawPoint { freq_hz, re, im })
            .collect(),
    })
}

use std::time::Duration;

/// One raw (uncorrected) S11 sweep at the given span. Blocking.
pub fn sweep_raw(start_hz: u64, stop_hz: u64, points: u32) -> Result<RawTrace, String> {
    if points == 0 {
        return Err("sweep needs at least 1 point".into());
    }
    if stop_hz <= start_hz {
        return Err("sweep stop frequency must be above the start".into());
    }

    let port_name = autodetect()?;
    let mut port = serialport::new(&port_name, 115_200)
        .timeout(Duration::from_millis(300))
        .open()
        .map_err(|e| format!("opening {port_name}: {e}"))?;

    // Wake the shell, drain anything pending.
    use std::io::Write;
    port.write_all(b"\r").map_err(|e| format!("serial I/O: {e}"))?;
    port.flush().map_err(|e| format!("serial I/O: {e}"))?;
    let _ = read_until_prompt(port.as_mut(), Duration::from_millis(500));

    // Disable on-device correction so we read the true raw reflection.
    run_command(port.as_mut(), "cal off")?;

    // Program the sweep span.
    run_command(
        port.as_mut(),
        &format!("sweep {start_hz} {stop_hz} {points}"),
    )?;

    // Let at least one full sweep complete before reading. The H sweeps ~2/s;
    // budget generously. (If this proves flaky, poll a status command instead —
    // see the device-verification note.)
    std::thread::sleep(Duration::from_millis(1200));

    let frequencies = run_command(port.as_mut(), "frequencies")?;
    let data = run_command(port.as_mut(), "data 0")?;

    // Be polite: re-enable device correction for standalone use.
    let _ = run_command(port.as_mut(), "cal on");

    parse_sweep(&frequencies, &data)
}
```

import type uPlot from "uplot";
import type { SwrPoint, TracePoint } from "./types";
import { HAM_BANDS } from "./bands";

export interface LabeledTrace { label: string; trace: TracePoint[]; }

/** Merge traces onto the union of their frequencies; a series carries `null`
 *  where it has no sample (uPlot draws a gap). No interpolation. */
export function swrSeries(traces: LabeledTrace[]): {
  x: number[];
  series: { label: string; y: (number | null)[] }[];
} {
  const freqSet = new Set<number>();
  for (const t of traces) for (const p of t.trace) freqSet.add(p.freq_hz);
  const x = [...freqSet].sort((a, b) => a - b);
  const index = new Map(x.map((f, i) => [f, i]));

  const series = traces.map((t) => {
    const y: (number | null)[] = new Array(x.length).fill(null);
    for (const p of t.trace) y[index.get(p.freq_hz)!] = p.swr;
    return { label: t.label, y };
  });
  return { x, series };
}

const BAND_FILL = "rgba(80,140,255,0.10)";

/** Shade amateur bands that fall within the current x-range. */
export function bandShadePlugin(): uPlot.Plugin {
  return {
    hooks: {
      draw: (u: uPlot) => {
        const { ctx } = u;
        const yTop = u.bbox.top;
        const yBot = u.bbox.top + u.bbox.height;
        ctx.save();
        ctx.fillStyle = BAND_FILL;
        for (const b of HAM_BANDS) {
          const x0 = u.valToPos(b.lo, "x", true);
          const x1 = u.valToPos(b.hi, "x", true);
          if (x1 < u.bbox.left || x0 > u.bbox.left + u.bbox.width) continue;
          ctx.fillRect(x0, yTop, Math.max(1, x1 - x0), yBot - yTop);
        }
        ctx.restore();
      },
    },
  };
}

/** Draw a marker + label at the minimum-SWR point. */
export function minSwrMarkerPlugin(getMin: () => SwrPoint | null): uPlot.Plugin {
  return {
    hooks: {
      draw: (u: uPlot) => {
        const m = getMin();
        if (!m || m.swr >= 999) return;
        const { ctx } = u;
        const px = u.valToPos(m.freq_hz, "x", true);
        const py = u.valToPos(m.swr, "y", true);
        ctx.save();
        ctx.fillStyle = "#e0245e";
        ctx.beginPath();
        ctx.arc(px, py, 4, 0, Math.PI * 2);
        ctx.fill();
        ctx.font = "12px system-ui, sans-serif";
        ctx.fillText(
          `${m.swr.toFixed(2)} : 1  @ ${(m.freq_hz / 1e6).toFixed(3)} MHz`,
          px + 8,
          py - 8,
        );
        ctx.restore();
      },
    },
  };
}

      ro.disconnect();
      chart?.destroy();
      chart = undefined;
    };
  });

  $effect(() => {
    // re-create on opts change (series count / plugins), just setData on data change
    if (chart && data) chart.setData(data);
  });

<script lang="ts">
  import { sweepRaw, saveCalibration } from "./api";
  import type { CalMeta, RawTrace } from "./types";

  let { ondone, oncancel }: { ondone: (m: CalMeta) => void; oncancel: () => void } = $props();

  let name = $state("");
  let notes = $state("");
  let startMhz = $state(1);
  let stopMhz = $state(30);
  let points = $state(101);

  const STEPS = ["open", "short", "load"] as const;
  let stepIdx = $state(-1); // -1 = params form; 0..2 = capture; 3 = solving
  let captured = $state<Partial<Record<(typeof STEPS)[number], RawTrace>>>({});
  let busy = $state(false);
  let error = $state<string | null>(null);

  const startHz = () => Math.round(startMhz * 1e6);
  const stopHz = () => Math.round(stopMhz * 1e6);

  function beginCapture() {
    error = null;
    if (!name.trim()) { error = "Give the calibration a name."; return; }
    if (stopHz() <= startHz()) { error = "Stop must be above start."; return; }
    if (points < 2 || points > 101) { error = "Points must be 2–101 (device limit)."; return; }
    stepIdx = 0;
  }

  async function captureCurrent() {
    busy = true; error = null;
    try {
      const which = STEPS[stepIdx];
      captured[which] = await sweepRaw(startHz(), stopHz(), points);
      if (stepIdx < 2) {
        stepIdx += 1;
      } else {
        stepIdx = 3;
        const meta = await saveCalibration(
          name, notes, startHz(), stopHz(), points,
          captured.open!, captured.short!, captured.load!,
        );
        ondone(meta);
      }
    } catch (e) {
      error = String(e);
      if (stepIdx === 3) stepIdx = 2; // let them retry the last capture
    } finally {
      busy = false;
    }
  }
</script>

<script lang="ts">
  import { onMount } from "svelte";
  import uPlot from "uplot";
  import { listCals, sweep, saveReading } from "./api";
  import type { CalMeta, Reading } from "./types";
  import UplotChart from "./UplotChart.svelte";
  import CalWizard from "./CalWizard.svelte";
  import { swrSeries, bandShadePlugin, minSwrMarkerPlugin } from "./plot";

  let cals = $state<CalMeta[]>([]);
  let selectedId = $state<string>("");
  let showWizard = $state(false);
  let reading = $state<Reading | null>(null);
  let busy = $state(false);
  let error = $state<string | null>(null);

  let saveName = $state("");
  let saveNotes = $state("");
  let saved = $state<string | null>(null);

  const selectedCal = $derived(cals.find((c) => c.id === selectedId) ?? null);

  async function refreshCals() {
    cals = await listCals();
    if (!selectedId && cals.length) selectedId = cals[0].id;
  }
  onMount(refreshCals);

  function ageDays(iso: string): number {
    return Math.floor((Date.now() - Date.parse(iso)) / 86_400_000);
  }

  async function doSweep() {
    if (!selectedId) return;
    busy = true; error = null; saved = null;
    try {
      reading = await sweep(selectedId);
    } catch (e) {
      reading = null;
      error = String(e);
    } finally {
      busy = false;
    }
  }

  async function doSave() {
    if (!reading || !saveName.trim()) return;
    busy = true; error = null;
    try {
      const meta = await saveReading(reading, saveName, saveNotes);
      saved = meta.name;
      saveName = ""; saveNotes = "";
    } catch (e) {
      error = String(e);
    } finally {
      busy = false;
    }
  }

  const plot = $derived.by(() => {
    if (!reading) return null;
    const { x, series } = swrSeries([{ label: reading.meta.name || "sweep", trace: reading.trace }]);
    const data: uPlot.AlignedData = [x, ...series.map((s) => s.y)];
    const logAxis = reading.meta.stop_hz / Math.max(1, reading.meta.start_hz) > 3;
    const opts: uPlot.Options = {
      width: 600,
      height: 360,
      scales: { x: { distr: logAxis ? 3 : 1 }, y: { range: [1, 5] } },
      axes: [
        { label: "MHz", values: (_u, ticks) => ticks.map((t) => (t / 1e6).toFixed(3)) },
        { label: "SWR" },
      ],
      series: [
        {},
        { label: series[0]?.label ?? "SWR", stroke: "#1769ff", width: 2 },
      ],
      plugins: [bandShadePlugin(), minSwrMarkerPlugin(() => reading?.min_swr ?? null)],
    };
    return { data, opts };
  });
</script>

<section>
  <div class="row">
    <label>
      Calibration
      <select bind:value={selectedId}>
        {#each cals as c (c.id)}<option value={c.id}>{c.name}</option>{/each}
      </select>
    </label>

  </div>

    <p class="muted">
      {(selectedCal.start_hz / 1e6).toFixed(3)}–{(selectedCal.stop_hz / 1e6).toFixed(3)} MHz ·
      {selectedCal.points} pts · {ageDays(selectedCal.created)} d old

  {/if}

<script lang="ts">
  import { onMount } from "svelte";
  import uPlot from "uplot";
  import { save } from "@tauri-apps/plugin-dialog";
  import {
    listReadings, getReading, renameReading, deleteReading, exportReading,
    listCals, renameCal, deleteCal, calUsage,
  } from "./api";
  import type { CalMeta, Reading, ReadingMeta } from "./types";
  import UplotChart from "./UplotChart.svelte";
  import { swrSeries, bandShadePlugin } from "./plot";

  let readings = $state<ReadingMeta[]>([]);
  let cals = $state<CalMeta[]>([]);
  let checked = $state<Set<string>>(new Set());
  let loaded = $state<Map<string, Reading>>(new Map());
  let error = $state<string | null>(null);
  let showCals = $state(false);

  async function refresh() {
    readings = await listReadings();
    cals = await listCals();
  }
  onMount(refresh);

  async function toggle(id: string) {
    const next = new Set(checked);
    if (next.has(id)) {
      next.delete(id);
    } else {
      next.add(id);
      if (!loaded.has(id)) {
        try {
          loaded = new Map(loaded).set(id, await getReading(id));
        } catch (e) {
          error = String(e);
          next.delete(id);
        }
      }
    }
    checked = next;
  }

  async function doRename(id: string, current: string) {
    const name = prompt("Rename reading", current);
    if (name && name.trim()) { await renameReading(id, name.trim()); await refresh(); }
  }
  async function doDelete(id: string) {
    if (confirm("Delete this reading? The .s1p and sidecar are removed.")) {
      await deleteReading(id);
      const c = new Set(checked); c.delete(id); checked = c;
      await refresh();
    }
  }
  async function doExport(id: string) {
    const dest = await save({ defaultPath: `${id}.s1p`, filters: [{ name: "Touchstone", extensions: ["s1p"] }] });
    if (dest) { try { await exportReading(id, dest); } catch (e) { error = String(e); } }
  }
  async function doRenameCal(id: string, current: string) {
    const name = prompt("Rename calibration", current);
    if (name && name.trim()) { await renameCal(id, name.trim()); await refresh(); }
  }
  async function doDeleteCal(id: string) {
    const n = await calUsage(id);
    const msg = n > 0
      ? `${n} reading(s) reference this calibration. They'll keep working but lose the cal name. Delete anyway?`
      : "Delete this calibration?";
    if (confirm(msg)) { await deleteCal(id); await refresh(); }
  }

  const single = $derived(checked.size === 1 ? loaded.get([...checked][0]) ?? null : null);

  const plot = $derived.by(() => {
    const traces = [...checked]
      .map((id) => loaded.get(id))
      .filter((r): r is Reading => !!r)
      .map((r) => ({ label: r.meta.name, trace: r.trace }));
    if (!traces.length) return null;
    const { x, series } = swrSeries(traces);
    const data: uPlot.AlignedData = [x, ...series.map((s) => s.y)];
    const span = x.length ? x[x.length - 1] / Math.max(1, x[0]) : 1;
    const palette = ["#1769ff", "#e0245e", "#17bf63", "#f45d22", "#794bc4"];
    const opts: uPlot.Options = {
      width: 600,
      height: 360,
      scales: { x: { distr: span > 3 ? 3 : 1 }, y: { range: [1, 5] } },
      axes: [
        { label: "MHz", values: (_u, ticks) => ticks.map((t) => (t / 1e6).toFixed(3)) },
        { label: "SWR" },
      ],
      series: [{}, ...series.map((s, i) => ({ label: s.label, stroke: palette[i % palette.length], width: 2 }))],
      plugins: [bandShadePlugin()],
    };
    return { data, opts };
  });
</script>

<section>
  <div class="grid">
    <ul class="list">
      {#each readings as r (r.id)}
        <li>
          <label>
            <input type="checkbox" checked={checked.has(r.id)} onchange={() => toggle(r.id)} />
            <span class="name">{r.name}</span>
            <span class="muted">{new Date(r.created).toLocaleDateString()} · {r.cal_name}</span>
